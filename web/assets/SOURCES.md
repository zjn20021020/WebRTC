# UI Asset Sources

These files are used for the local Roco Kingdom: World themed voice demo.
Game artwork belongs to its original rights holders; it is not original
artwork of this repository and is not relicensed by this project.

- `home-landscape.webp`: official landscape screenshot, cropped to remove the
  photo border and converted to WebP.
  https://game.gtimg.cn/images/rocom/web202507/index/part3/photo/8.png
- `dimo.webp`: first Dimo sticker in the official two-frame sprite, cropped
  and converted to lossless WebP.
  https://game.gtimg.cn/images/rocom/web202507/index/part2/sprite/1.png
- Source page: https://rocom.qq.com/main/ (accessed 2026-09-12).
- `icons/*.svg`: Lucide Static 0.468.0, ISC license retained in `icons/LICENSE`.
  https://unpkg.com/lucide-static@0.468.0/icons/

Game artwork is a visual reference for the demo; it does not demonstrate an
implemented game connection or a verified in-game home scene.
